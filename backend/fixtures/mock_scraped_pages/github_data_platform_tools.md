# data-platform-tools

A collection of internal tools the data platform team uses, open-sourced for the community.

## Repositories

- `kafka-tap` - lightweight CDC tap from Postgres to Kafka
- `dbt-quality-checks` - shared dbt macros for data quality assertions
- `snowflake-cost-watch` - Slack-bot that surfaces high-cost Snowflake queries
- `airflow-runbooks` - tested Airflow operators for common platform tasks

## Status

Active. Maintained by the data platform team. Contributions welcome.

## Tech

- Python 3.12
- Kafka, Snowflake, dbt, Airflow
- GitHub Actions for CI
